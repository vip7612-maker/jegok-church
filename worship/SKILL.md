# 주일예배 찬양 준비 (제곡교회)

교장님이 매주(주로 금·토) 주일 찬양예배 인도를 준비할 때 두 단계로 돕는다. 되묻지 말고 실행하고, 스크립트가 찍는 마지막 요약 블록을 그대로 답한다.

## 1단계 — "예배 준비하자" → 사전 세팅

```bash
python3 ~/dev/jegok-church/worship/prep.py
```
- 다음 주일(오늘이 일요일이면 오늘) 폴더 `2026 MMDD 주일예배 이경진` 를 「2026 예배찬양」에 만들고, 「예배준비 템플릿」의 악보 슬라이드·주일예배 PPT 를 날짜 이름으로 복사하며 표지 날짜를 바꾼다. 이미 있으면 건너뜀.
- 옵션: `--date YYYY-MM-DD` · `--leader 이름`(기본 이경진) · `--suffix 부활주일` · 텔레그램 요청이면 `--notify`.
- **답장 끝에 꼭 붙인다**: "주보 HWP 파일을 올려주시면 PDF로 바꿔 폴더에 넣고, 설교 본문에 맞는 찬양 콘티(CCM 20곡·찬송가 10곡)를 추천해 드리겟습니다. 한글에서 내보낸 PDF도 있으면 함께 올려주세요(레이아웃이 정확합니다)."

## 2단계 — 주보 HWP 가 오면 → PDF 변환 + 콘티 추천

첨부 안내(`[사용자가 문서 파일을 첨부했습니다: <경로>]`)의 경로가 `.hwp` 이면:
```bash
python3 ~/dev/jegok-church/worship/conti.py "<hwp 경로>" [--pdf "<pdf 경로>"] [--notify]
```
- 날짜는 파일명(`20260920 …`)에서 읽고, 없으면 다음 주일. 다른 날이면 `--date`.
- 하는 일: kordoc 으로 본문 읽기 → 설교 제목·성경 본문·요약 추출 → HWP 와 PDF 를 그 주일 폴더에 `YYYYMMDD 주일 주보.hwp/.pdf` 로 저장(PDF 를 같이 받았으면 그것을, 없으면 자동 변환본 — 이름에 "(자동변환·레이아웃 근사)" 표시) → Claude 가 교회 레퍼토리(「콘티 기록」 문서 285곡·코드)를 우선해 CCM 20곡(빠른 6·중간 8·느린 6) + 새찬송가 10곡(3·4·3) 추천 → 찬송가 장수는 유튜브 제목으로 검증, 곡마다 유튜브 링크 → 결과를 폴더에 `YYYYMMDD 콘티 추천` 구글문서로도 저장.
- 3분쯤 걸린다. 텔레그램이면 먼저 "주보 받았습니다, 콘티 추천까지 3분 정도 걸립니다" 라고 한 줄 보내고 실행한다.
- 출력 형식(그대로 전달):
  ```
  🎵 9/20(일) 주일예배 콘티 추천
  설교 「제목」 (본문)
  [CCM 20곡]
  <빠른곡>
  1. 곡명 G코드 https://…
  <중간곡> … <느린곡> …
  [찬송가 10곡]
  <빠른곡>
  1. 305장 곡명 G코드 https://…
  ```
- `(장수 확인 필요)` 표시가 붙은 찬송가는 번호 검증에 실패한 후보다 — 그대로 전달하되 그 표시를 지우지 않는다.

## 실패했을 때
- `구글 토큰 갱신 실패` → 재인증 필요: `cd ~/dev/next_api_bot && node scripts/google-auth.mjs` (교장님이 브라우저로), 이후 daily-briefing/.env 갱신.
- `kordoc 변환 실패` → 파일이 HWP 5.x 인지 확인(HWPX·PDF 도 kordoc 이 읽으니 `conti.py` 에 그대로 넘겨도 된다).
- `hwp5html 없음` → `cd ~/dev/jegok-church && /Library/Frameworks/Python.framework/Versions/3.12/bin/python3 -m venv .venv && .venv/bin/pip install -r worship/requirements-hwp.txt`
- 그 외 오류는 메시지를 그대로 전하고 드라이브 폴더 링크(https://drive.google.com/drive/folders/1sRJ7X8heOaM5BmDa0WW6Jvs__O2upcpV)를 함께 준다.

## 하지 않는 것
- 최종 콘티 확정·「콘티 기록」 문서 기입은 교장님이 한다(추천은 후보). 주보 작성도 범위 밖.
