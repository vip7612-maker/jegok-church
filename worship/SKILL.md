# 주일예배 찬양 준비 — 사전 세팅

교장님이 매주(주로 금·토) 제곡교회 주일 찬양예배 인도를 준비하기 전에 하는 **폴더·파일 세팅**을 대신한다.
되묻지 말고 바로 실행한 뒤 결과(폴더·파일 링크)만 보고한다.

## 실행

```bash
python3 ~/dev/jegok-church/worship/prep.py
```

- 기본 대상 = **다음 주일**(오늘이 일요일이면 오늘). 교장님이 날짜를 말하면 `--date YYYY-MM-DD`.
- 인도자가 다른 사람이면 `--leader 이름` (기본 이경진). "부활주일" 같은 말을 붙이라 하면 `--suffix 부활주일`.
- 텔레그램에서 요청받았을 때(워커)는 `--notify` 를 붙이면 경진비서방에도 같은 결과가 간다. 답장은 스크립트 출력(마지막 요약 블록)을 그대로 쓴다.
- 먼저 무엇이 만들어질지만 보려면 `--dry-run`.

## 스크립트가 하는 일 (규칙은 드라이브의 기존 폴더들에서 그대로 따왔다)

1. 폴더 `2026 MMDD 주일예배 이경진` 를 「2026 예배찬양」(공유 드라이브 `1sRJ7X8heOaM5BmDa0WW6Jvs__O2upcpV`) 안에 생성
2. 「예배준비 템플릿」 두 파일을 그 폴더로 복사 — 이름의 `0000` → `MMDD`
   - 구글 슬라이드 「2026 0000 반주자 및 싱어용 악보」 → 표지 `2026.00.00` → `2026.MM.DD` (Slides API)
   - 파워포인트 「2026 0000 주일예배 PPT」(.pptx 유지) → 표지 `2026년  00월 00일` → 실제 날짜 (XML 수정 후 업로드)
3. 이미 있는 폴더/파일은 다시 만들지 않는다(두 번 실행해도 안전)

## 실패했을 때
- `구글 토큰 갱신 실패` → 구글 재인증이 필요하다(비밀번호 변경 뒤 흔함): `cd ~/dev/next_api_bot && node scripts/google-auth.mjs` 를 교장님이 브라우저로. 재인증 후 daily-briefing/.env 도 갱신.
- 그 외 오류는 메시지를 그대로 전하고, 드라이브 폴더 링크(https://drive.google.com/drive/folders/1sRJ7X8heOaM5BmDa0WW6Jvs__O2upcpV)를 함께 준다.

## 하지 않는 것
- 찬양 콘티(곡 선정)·주보 작성은 이 스킬의 범위가 아니다. 세팅 뒤 "다음으로 콘티 작업 하시겠어요?" 한 줄만 덧붙인다.
